# Dots installation

1. Confirm the customer's ChatGPT account has a dot. Give the dot this kit folder on its cloud computer, or connect the customer's computer and grant access to the chosen local kit and data folders. Do not rely on a one-time chat attachment as persistent storage.
2. Tell the dot to read SKILL.md and ROLE.md, show the selected paths, and run one routine now. Inspect its written brief and run log on the same computer.
3. Ask the dot to schedule each routine at the cadence in SCHEDULE.md. Review each saved task under Scheduled, including its target computer and repeat time.
4. Verify the first scheduled run uses the same kit and author data. If the target computer changes, inspect the saved task again; tasks do not automatically move with the dot's selected computer.
5. Keep the dot's connected apps limited to this role's needs. The free roles require no private account connection.

Dots are available only on eligible accounts and regions.
