# Muse installation

Muse personal agent and Muse Code are different paths. Confirm which one the customer has.

## Muse personal agent
1. Place this kit and author data on Muse's persistent computer if available, and ask Muse to read SKILL.md and identify the exact files it will use.
2. Run one routine now; inspect the written output and log.
3. Ask Muse to schedule each routine from SCHEDULE.md, then review the saved recurring tasks and first results. If the kit folder is not retained between runs, use manual mode until persistence is confirmed.

## Muse Code
1. Open the kit as the trusted workspace and authenticate using the customer's own account.
2. Run `muse exec` with a prompt to read one routine and its author data; inspect the output.
3. Use Muse Code's scheduled prompt facility only while its session persists, or use the operating-system scheduler to invoke `muse exec` for durable recurring runs. Test the actual scheduled invocation.

No connector, password, or account is installed by the kit.
