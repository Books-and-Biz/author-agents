# Install Author Site Path Watch

1. Keep this kit in one persistent folder. Choose a separate data folder owned by the author; make one data folder per pen name when relevant.
2. Copy the files from templates/ into the data folder and fill only confirmed facts. Never put passwords or API keys in a template.
3. Open the kit in the chosen agent and ask it to read SKILL.md and ROLE.md. Select the first routine in SCHEDULE.md and run it manually.
4. Inspect the dated output and Run Log.csv. Correct source facts before scheduling.
5. Follow one file in adapters/ for Codex, Claude, Dots, Grok Bots, Muse, or manual use. Create one scheduled task per routine only after the manual run succeeds.
6. Check the first *scheduled* run; interactive success alone does not prove unattended file or connector access.

The author's agent account, usage, and optional connected services are separate from the kit.
