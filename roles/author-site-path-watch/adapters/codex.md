# Codex installation

1. Extract this one kit to a persistent workspace. Open that folder in Codex.
2. Ask: `Read SKILL.md and install this role for my author workspace.` Choose a data folder outside the kit.
3. Run the first routine manually with `Read routines/<id>/SKILL.md and follow it for my selected workspace.` Inspect its dated output and Run Log.csv.
4. Create one Codex automation per routine using the same prompt, the kit as working directory, and the author's chosen local time zone. Confirm the first scheduled run can read the data folder and write the log.
5. Pause or remove a routine in Codex when the author no longer wants it. Do not infer that an automation exists merely because SCHEDULE.md lists a cadence.

Codex app automation availability and account capabilities must be checked on the customer's own installation.
