# Grok Bots installation

1. Confirm the customer has Grok Bot. Put this kit and the chosen author data folder on the Bot's persistent cloud computer.
2. Name or select a Bot for the role. Ask it to read SKILL.md and ROLE.md, confirm the paths, and run one routine now. Inspect the brief and run log on its computer.
3. Create one recurring Bot routine per SKILL.md in SCHEDULE.md. The prompt names the exact kit and data paths. Use Run now and then inspect the first scheduled result.
4. All Bots on the account share the same cloud files and sign-ins. The free roles need only public pages or customer files; do not connect private accounts for them.
5. Pause a Bot routine when the author stops using the role.
