# Page Check

Read `../../ROLE.md` and the selected workspace. Suggested cadence: Tuesday and Friday.

For each configured public URL, open the page if the host has browsing. Record check time, region, final URL, reachable/failed/unknown, and visible title, pen name, and format. Compare only observed fields. Write exceptions with source URL and evidence. If browsing is unavailable, record unknown and a manual-check task.

Write the output named in ROLE.md and one Run Log.csv row. Include confirmed facts, proposed actions, unknowns, and source evidence. A repeated run on the same date updates the previous output with a change note. If a required source or capability is absent, record a partial or blocked run and the next manual step. Do not take any external action.
