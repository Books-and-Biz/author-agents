# Weekly Launch Map

Read `../../ROLE.md` and the selected workspace. Suggested cadence: Monday.

Read Launch.csv. Show this week's dated milestones, dependencies, owners, and missing decisions. Separate confirmed dates from targets. Prepare one brief for the selected book.

Write the output named in ROLE.md and one Run Log.csv row. Include confirmed facts, proposed actions, unknowns, and source evidence. A repeated run on the same date updates the previous output with a change note. If a required source or capability is absent, record a partial or blocked run and the next manual step. Do not take any external action.
