# Launch Deadline Desk

Read ROLE.md and INSTALL.md. For an on-demand request, choose the matching routine in SCHEDULE.md. Before doing the job, read that routine's SKILL.md. The author selects the data workspace. Never treat the kit folder as the author's data folder. Available routines: weekly-launch-map, deadline-check, launch-closeout.
